Esse software foi desenvolvido para uso interno na Indústria de Calçados Wirth LTDA.
Desenvolido com o objetivo de permitir o usuário mesclar vários documentos PDF's em um único arquivo.
 
## ✅ Principais vantagens
A principal vantagem da utilização desse software é a privacidade que o usuário possui ao usar um sistema offline que roda localmente em sua máquina.
Além disso, o usuário não possui um limite de arquivos ou de tamanho.
 
## 🚀 Começando
Essas instruções permitirão que você obtenha uma cópia do projeto em operação na sua máquina local para fins de desenvolvimento e teste.
 
## 📝 Como executar o software
Caso deseje somente executar o sistema, o executável está localizado em:
 
-> Mesclar PDF <br> 
-> dist <br> 
-> Mesclar PDF.exe
 
Agora basta salvar ele em sua área de trabalho e ele estará pronto para uso!
 
## 🔨 Como foi feito
O software foi feito usando Python e bibliotecas como PyPDF2 e Tkinter.
Abaixo você encontra um passo a passo de como instalar as bibliotecas, rodar o código e criar um executável.
 
***1*** - Instale o Python (link disponível no trecho "Construído com"). <br>
***2*** - Instale a sua IDE de preferência. <br>
***3*** - Instale a biblioteca PyPDF2, para isso abra o cmd ou o terminal de sua IDE e digite o comando ```pip install PyPDF2```. <br>
***4*** - Após as etapas acima já é possivel realizar O código foi desenvolvido (o código pode ser encotrado pelo nome ```merge_pdfs_gui.py```).<br>
***5*** - Para testar se o código e a interface estão como o desejado, abra o terminal de sua IDE ou o CMD de seu computador e execute o comando ```python merge_pdfs_gui.py```.<br>
***6*** - Instale o Pyinstaller usando o comando ```pip install pyinstaller```, com isso é possível transformar o código em um arquivo executável.<br>
***7*** - No CMD ou terminal de sua IDE, navegue até o local que o seu código se encontra e execute o comando ```pyinstaller --onefile --noconsole merge_pdfs_gui.py``` (caso tenha mudado o nome do arquivo, altere na hora de executar o comando também)<br>

## 🔨 How it was made
The software was built using Python and libraries such as PyPDF2 and Tkinter.
Below you will find a step-by-step guide on how to install the libraries, run the code, and create an executable file.
 
***1*** - Install Python (link available in the "Built with" section). <br>
***2*** - Install your preferred IDE. <br>
***3*** - Install the PyPDF2 library. To do this, open the CMD or your IDE’s terminal and type the command ```pip install PyPDF2```. <br>
***4*** - After completing the steps above, you can run the code (the code can be found under the name merge_pdfs_gui.py). <br>
***5*** - To test if the code and interface are as desired, open the terminal in your IDE or your computer’s CMD and run the command: python merge_pdfs_gui.py. <br>
***6*** - Install PyInstaller using the command: pip install pyinstaller. This will allow you to turn the code into an executable file. <br>
***7*** - In CMD or your IDE’s terminal, navigate to the location where your code is stored and run the command: pyinstaller --onefile --noconsole merge_pdfs_gui.py (if you have changed the file name, update it when running the command as well). <br>
